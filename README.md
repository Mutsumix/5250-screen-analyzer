# Screen Friend - RPG学習支援アシスタント

## 概要
Screen Friendは、IBM i (AS/400) のRPG言語学習を支援するデスクトップアプリケーションです。ユーザーが質問を入力したときに5250ターミナルエミュレータの画面を分析し、AIを活用してリアルタイムで操作ガイダンスを提供します。

## 設計方針
### AI通信モデル
- **ユーザー主導型**: ユーザーが質問を入力したときのみLLM APIを呼び出し
- **コスト効率**: 常時監視ではなく、必要時のみの通信でAPI料金を抑制
- **画像処理**: 質問送信時に画面キャプチャを実行し、OCRまたは画像直接送信

### 対応LLMプロバイダー
- **OpenAI**: GPT-4o, GPT-4o-mini
- **Anthropic**: Claude 3.5 Sonnet

### コスト見積もり（100回のやり取り）
- **OCR送信**: 3-70円（推奨）
- **画像直接送信**: 66-120円（高精度）

### 新しいUI設計方針
#### レイアウト構成
- **左側**: 5250ターミナル操作画面
- **右側上部**: 質問入力エリア
- **右側下部**: AI回答表示エリア

#### 操作方法
1. **質問入力**: テキストエリアに質問を入力
2. **送信方法の選択**:
   - **「📝 Text Only」ボタン**: テキストのみでAIに質問
   - **「📷 With Screen」ボタン**: 画面キャプチャと一緒にAIに質問
3. **AI回答**: 下部エリアに回答が表示

#### 削除される機能
- **自動キャプチャ機能**: 設定時間ごとの自動キャプチャを廃止
- **Start/Pauseボタン**: 常時監視機能を削除
- **captureInterval設定**: API破産防止のため削除

## 主な機能
- **質問入力機能**: 右上エリアでの直感的な質問入力
- **2つの送信方式**: 
  - 📝 テキストのみでの質問
  - 📷 画面キャプチャと一緒の質問
- **5250ターミナル画面の手動キャプチャ**
- **OCRによる画面内容の認識**
- **AI（OpenAI/Anthropic）による操作アドバイスの生成**
- **ユーザー質問に対するリアルタイム回答**
- **学習履歴の保存**

## 動作環境
- Windows 10/11（主要ターゲット）
- macOS（開発・検証用）
- Node.js 18以上
- IBM i Access for Windows（または互換5250エミュレータ）

## セットアップ手順

### 1. リポジトリのクローン
```bash
git clone <repository-url>
cd screen-friend
```

### 2. 依存関係のインストール
```bash
npm install
```

### 3. 環境設定
```bash
cp .env.example .env
```
`.env`ファイルを編集し、以下の設定を行います：
- `OPENAI_API_KEY`: OpenAI APIキー（GPT使用時）
- `ANTHROPIC_API_KEY`: Anthropic APIキー（Claude使用時）

### 4. 開発モードで起動
```bash
npm run dev
```

### 5. ビルド（本番用）
```bash
# Windows用
npm run build:win

# macOS用
npm run build:mac
```

## 使用方法

### 初回設定
1. アプリケーションを起動
2. 設定画面で5250ターミナルウィンドウの位置を指定
3. AIプロバイダー（OpenAI/Anthropic）を選択
4. 必要に応じてAPIキーを設定

**注意**: 自動キャプチャ設定（captureInterval）は削除されました。手動での質問時のみAIが動作します。

### 基本的な使い方
1. 5250ターミナルを指定した位置に配置
2. 右上の質問入力欄に困っていることを入力
3. 送信方法を選択：
   - **「📝 Text Only」**: テキストのみでAIに質問
   - **「📷 With Screen」**: 画面キャプチャと一緒にAIに質問
4. 右下に表示されるAIからの回答を参考に学習を進める

### ショートカットキー
- `Ctrl+Shift+C`: 現在の画面を手動キャプチャ
- `Ctrl+Shift+H`: 履歴の表示

## トラブルシューティング

### 画面が認識されない場合
- ターミナルウィンドウが指定位置に正しく配置されているか確認
- OCR精度設定を調整（設定画面から）
- 「📷 With Screen」ボタンを使用して画面キャプチャが正常に動作するか確認

### APIエラーが発生する場合
- APIキーが正しく設定されているか確認
- ネットワーク接続を確認
- 使用量上限に達していないか確認

### 質問が送信されない場合
- 質問テキストが入力されているか確認
- 使用するAIプロバイダー（OpenAI/Anthropic）が正しく選択されているか確認
- 「📝 Text Only」と「📷 With Screen」の違いを理解して適切なボタンを選択
